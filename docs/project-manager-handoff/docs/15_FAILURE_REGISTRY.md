# Failure Registry

## Zweck

Diese Datei hält bekannte Fehler fest, damit sie nicht wiederholt werden.

## Bekannte Fehler

1. Lokale Fake-Skills wurden statt Master-Skills genutzt.
2. Sourcecode wurde mit Runtime verwechselt.
3. Vertrauliche Werte wurden in Ausgaben sichtbar.
4. Legacy-Systeme wurden als aktive Zukunftssysteme behandelt.
5. Kundenprojekte wurden im Plattform-Core vermischt.
6. Es wurde zu früh eine große Plattform gebaut, statt das Hauptgeschäft zu stabilisieren.
7. Halbfertige Artefakte wurden angelegt und nicht klassifiziert.

## Korrekturprinzip

Jeder Fehler erzeugt mindestens eine Prevention Rule, einen Brain-Eintrag und bei Bedarf eine DOS- oder Governance-Erweiterung.

## Aktuelle Sonderprüfung

Die unfertige Bridge-Struktur unter `/opt/nexify/anton-goose-bridge/` muss inventarisiert, migriert, quarantänisiert oder als blocked dokumentiert werden. Sie darf nicht unklar aktiv bleiben.
