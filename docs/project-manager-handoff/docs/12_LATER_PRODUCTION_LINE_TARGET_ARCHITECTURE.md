# Later Target Architecture

Diese Architektur bleibt Zielbild, wird aber erst nach Business-Stabilisierung umgesetzt.

Komponenten:

- interne Project Manager Control Plane
- Goose als isolierter Worker
- Brain als Governance- und Langzeitkontext
- GitHub als Source of Truth
- Event- und Automation-Layer
- langlebige Workflow-Orchestrierung
- zentraler Tool-Gateway
- Experten-Agenten für Plattform, Security, UX, Architektur und Betrieb
- Modell- und Routing-Schicht
- Token- und Output-Optimierung

Die Einführung erfolgt stufenweise. Jede neue Stufe muss Business, Delivery und Stabilität direkt verbessern.
