# Reporting and Evidence

## Pflichtbericht

Jede Aufgabe endet mit einem strukturierten Abschlussbericht.

## Mindestinhalt

- Task-ID
- Ziel
- Status
- geänderte Dateien
- Branch
- Commit
- Pull Request
- Tests und Ergebnis
- CI Status
- Security Check
- Brain Update
- offene Blocker
- Risiken
- nächster sicherer Schritt

## Evidence-Arten

- Git Evidence: Branch, Commit, PR, Diff
- Test Evidence: Testbefehl, Ergebnis, Logs ohne vertrauliche Werte
- CI Evidence: Checks, Jobnamen, Status
- Runtime Evidence: Healthcheck, Domain, Container, Logauszug ohne vertrauliche Werte
- Brain Evidence: Kategorien und gespeicherte Zusammenfassung

## Ablehnung

Eine Fertigmeldung ohne Evidence wird abgelehnt und erzeugt einen Folgeauftrag zur Nachbesserung.
