# Start Sequence

## Schritt 1: Kontrollierte Übernahme

Der neue Project Manager lädt diese Übergabe, prüft Brain-Zugriff, bestätigt GitHub Source of Truth und erzeugt den ersten Read-only-Auftrag für Goose.

## Schritt 2: Business Reality Audit

Goose prüft nur lesend:

- Agenturseite
- Kundenprojekte
- GitHub/Security/CI
- Runtime-Systeme
- offene Blocker

## Schritt 3: Priorisierung

Der Project Manager erstellt P0/P1/P2/P3 und beauftragt zuerst geschäftskritische Fixes.

## Schritt 4: Agenturseite

Kontakt, Angebotspfad, Beratungsfunktion, Branding, Tracking und Deployment werden stabilisiert.

## Schritt 5: Kundenprojekte

Jedes Kundenprojekt bekommt separaten Plan, Pflichtenheft-Abgleich und Livegang-Checkliste.

## Schritt 6: Security und CI

Release-Blocker werden gelöst, ohne die Business-Arbeit zu verzögern.

## Schritt 7: Späterer Ausbau

Erst nach Stabilisierung wird die vollständige Produktionsstraße ausgebaut.
