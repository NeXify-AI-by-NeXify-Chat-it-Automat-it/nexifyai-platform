# Goose Prompt: Kundenprojekt Audit Template

AUFGABE: Einzelnes Kundenprojekt read-only prüfen.

MODUS: Read-only. Keine Dateien ändern. Keine Services ändern. Keine vertraulichen Werte ausgeben.

## Eingaben

- Projektname
- Kunde
- Repo oder lokaler Pfad
- Domain
- Pflichtenheft oder Kundenvorgaben

## Ziel

Ermittle, was bis Livegang, Abnahme oder Übergabe fehlt.

## Prüfen

- Source of Truth
- Pflichtenheft
- aktuelle Umsetzung
- offene Bugs
- fehlende Inhalte
- Design-Abweichungen
- Auth und Rollen
- Datenbank und Schnittstellen
- Deployment
- Domain
- CI/CD
- Security und Datenschutz
- Performance
- Abnahmekriterien

## Ergebnis

- Status
- Livegang-Blocker
- Risiko
- Aufwandsschätzung
- erste sichere Umsetzungsreihenfolge
- empfohlener Branch
- Brain Update
