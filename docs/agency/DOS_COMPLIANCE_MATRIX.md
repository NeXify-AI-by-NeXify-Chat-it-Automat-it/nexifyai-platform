# NeXifyAI DOS Compliance Matrix

## Compliance-Realitätsregel
- ISO/DIN/Normen nur als erfüllt markieren, wenn konkrete Anforderungen und Nachweise vorhanden
- Keine falschen Compliance-Behauptungen
- Jede Compliance-Aussage braucht Quelle, Status und Evidence
- Wenn konkrete Normanforderungen fehlen: Compliance-Lücke markieren

## Geltende Standards (zur Prüfung)
- DSGVO: Datenschutz, Rechtsgrundlagen, Betroffenenrechte, Auftragsverarbeitung
- ISO 27001: Informationssicherheit, ISMS, Risikomanagement
- ISO 9001: Qualitätsmanagement
- ISO 42001: KI-Management
- BSI-Grundschutz: IT-Sicherheit
- WCAG 2.2 AA: Barrierefreiheit
- OWASP ASVS: Anwendungssicherheit
- SOC2: Sicherheit, Vertraulichkeit
- EU AI Act: KI-Regulierung
- ISO 27701: Datenschutz-Management
