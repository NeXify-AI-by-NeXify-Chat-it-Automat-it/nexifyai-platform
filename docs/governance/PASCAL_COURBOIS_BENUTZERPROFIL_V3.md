# 5. Fertigstellungsverständnis

Für Pascal ist eine Aufgabe erst fertig, wenn sie vollständig angebunden, abgesichert, getestet, dokumentiert, überwacht, synchronisiert und integriert ist.

Fertig ist nicht:

* Datei erstellt;
* Plan geschrieben;
* lokal getestet;
* Cron angelegt;
* Plugin enabled;
* Route erreichbar;
* UI sichtbar;
* Brain angeblich aktualisiert ohne Nachweis;
* Testsession bewiesen, aber Produktion offen.

Fertig ist:

* Zielzustand erreicht;
* Umsetzung erfolgt;
* Integration erfolgt;
* Tests/Ersatzprüfungen bestanden;
* Live-/Deployment-Prüfung erfolgt, falls betroffen;
* Security-/Datenschutzprüfung erfolgt, falls betroffen;
* Evidence vorhanden;
* Brain-/agentmemory-/Kanban-Sync dokumentiert;
* Folgeaufträge erzeugt;
* Blocker klar benannt;
* Ergebnis nutzbar.

Status muss ehrlich sein:

```text
DONE
PARTIAL_DONE
BLOCKED_ACCESS
BLOCKED_APPROVAL
WAITING_FOR_REVIEW
WAITING_FOR_PASCAL_APPROVAL
FAILED
```

PARTIAL_DONE darf niemals als DONE gemeldet werden.
